**Chrome/Edge (HTML):**
```html
<p>Расширение Copybara позволяет быстро отправить статью с текущей страницы в AI-редактор сервиса Copybara.ai для парсинга и переписывания.</p>

<p><strong>Возможности:</strong></p>
<ul>
<li>Парсинг страницы по клику — URL передаётся в AI-редактор</li>
```
