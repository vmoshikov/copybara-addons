# Скриншоты для Chrome Web Store

Требования: 1280×800 или 640×400 px, минимум 1, максимум 5.

## Как сделать

1. Загрузите расширение в Chrome (chrome://extensions → Режим разработчика → Загрузить распакованное)
2. Откройте любую веб-страницу (например, статью)
3. Кликните по иконке расширения — откроется popup
4. Сделайте скриншот popup (можно использовать DevTools: правый клик по popup → Inspect → скриншот узла)
5. Или: увеличьте масштаб страницы до 200–300%, чтобы popup был крупнее, и сделайте скриншот экрана
6. Обрежьте до 1280×800 или 640×400

Сохраните в `store/chrome/screenshots/` как screenshot-1.png, screenshot-2.png и т.д.
